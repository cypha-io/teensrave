Place your dreamFont files here:

- dreamFont.woff2 (preferred format for modern browsers)
- dreamFont.woff (fallback format)

The font-face declaration in globals.css expects these files to be located at:
/public/fonts/dreamFont.woff2
/public/fonts/dreamFont.woff

Once you add the actual font files, the dreamFont will be applied to the TEENSRAVE and FESTIVAL text.
